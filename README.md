# Ferrari Helmet Hover

Локальный демонстрационный проект на React + Vite, переработанный из примера `Ferrari-Helmet-Hover.html`.

## Краткое описание

Интерактивное SPA с карточками Ferrari, эффектами обложки/шлема и переключаемыми наборами данных (гаражи, пилоты и т.д.). Проект служит демонстрацией компонентов UI, простых анимаций и организации данных.

## Быстрый старт

1. Установить зависимости:

```bash
npm install
```

2. Запустить dev-сервер:

```bash
npm run dev
```

3. Сборка для продакшна:

```bash
npm run build
```

4. Предпросмотр собранного билда:

```bash
npm run preview
```

## Технологии

- React 19
- Vite + @vitejs/plugin-react
- CSS (src/styles.css, src/cover.css)

## Структура и назначение файлов (полное описание)

- src/
  - App.jsx — Главный container-приложения. Управляет состоянием (gameId, driverId, меню игры, loading) и собирает страницы: Cover, Header, Hero, Garage, Pilots, Tracks, Ticker.
  - main.jsx — Точка входа React (createRoot).
  - styles.css — Основные стили интерфейса, дизайн сетки, адаптивность.
  - cover.css — Стили для обложки/эффекта шлема и loading-screen.
  - pilotGarage.js — Утилита/данные для динамического обновления карточек гаража (ручные данные гаражей/машин и DOM-манипуляции для некоторых переходов).

- src/components/
  - Header.jsx — Навигация/верхняя панель, кнопки управления меню игры и утилиты.
  - Hero.jsx — Большой «герой»-блок с названием, описанием и CTA (переход к Garage).
  - Garage.jsx — Секция с сеткой карточек автомобилей (car-card). Отвечает за визуальную презентацию гаража.
  - Pilots.jsx — (новый) Секция «Пилоты»/команда. Компонент принимает props: activeId, onChange и рендерит список пилотов; управляет выбором активного пилота.
  - Tracks.jsx — (новый) Секция треков/навигации — рендерит список навигационных пунктов или трасс.
  - Team.jsx — Старая версия компонента команды (оставлена для совместимости/резерва). Сейчас App.jsx использует Pilots.jsx вместо Team.jsx.
  - Ticker.jsx — Нижняя бегущая строка (marquee) с информацией/актуалом.
  - Cover.jsx — Компонент обложки и наложения загрузки (loading-screen).
  - другие компоненты в папке components/ (Hero, Header, Ticker, и т.д.) — см. реализацию для деталей.

- src/data/
  - pilots/ — данные по пилотам (используются Pilots/Team)
  - games/ — список игр/настроек (используется для gameMenu)
  - cars/, tracks/, ticker/ — вспомогательные данные для карточек и бегущей строки

- public/images/ — Статичные изображения для обложки и карточек (см. public/images/README.md для списка ожидаемых файлов).
- vite.config.js — Конфигурация сборки Vite.
- package.json — Скрипты (dev, build, preview) и зависимости.

## Примеры использования кода

- Для изменения списка пилотов — редактировать `src/data/pilots/index.js`.
- Для изменения карточек гаража — редактировать `src/pilotGarage.js` или `src/data/cars/*`.
- Чтобы добавить изображение карточки — положить файл в `public/images/` и обновить путь в компоненте, который рендерит картинку.

## Советы по разработке

- App.jsx централизует состояние страницы; новые секции добавлять как отдельные компоненты и подрубать через пропсы (activeId/onChange и т.д.).
- pilotGarage.js содержит прямые DOM-манипуляции — при переводе логики полностью на React можно переписать его в виде хука или менеджера состояния.
- Для визуальных правок редактировать src/styles.css и src/cover.css.
